# Security Policy

## Supported scope

Security reports related to LokiProxy documentation, examples, repository configuration, and published project files are welcome.

## Reporting a security issue

Please do not publish sensitive security details in a public GitHub issue.

When reporting a security issue, provide:

- A clear description of the issue.
- Steps to reproduce the issue when possible.
- The affected file, page, or component.
- The potential security impact.
- A suggested mitigation if available.

## Do not include secrets

Never include the following information in a public issue or pull request:

- Real proxy usernames.
- Real proxy passwords.
- API keys.
- Private tokens.
- Private server credentials.
- Other sensitive authentication information.

Use placeholders instead:

```text
USERNAME
PASSWORD
HOST
PORT
