# Code of Conduct

## Our commitment

We are committed to maintaining a welcoming, respectful, and constructive community.

Everyone participating in the LokiProxy project is expected to communicate professionally and respectfully.

## Expected behavior

Examples of positive behavior include:

- Being respectful and constructive.
- Providing useful technical feedback.
- Accepting different technical opinions.
- Focusing discussions on the project and its documentation.
- Helping other contributors when possible.

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment or personal attacks.
- Discriminatory or hateful comments.
- Threats or intimidation.
- Publishing private information.
- Deliberately disrupting project discussions.
- Posting credentials, API keys, or other secrets.

## Reporting

If you encounter unacceptable behavior, please report it privately to the project maintainers through the appropriate GitHub communication channel.

Do not publish sensitive information in a public issue.

## Enforcement

Project maintainers may remove content, close discussions, or restrict participation when necessary to maintain a respectful project environment.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, documentation, and other project-related communication spaces.
