# Contributing to LokiProxy

Thank you for your interest in contributing to LokiProxy.

LokiProxy documentation and examples focus on HTTP and SOCKS5 proxy connections and practical developer integration.

## Before contributing

Please check the existing documentation and examples before opening an issue or pull request.

Make sure that your contribution:

- Is relevant to LokiProxy.
- Is technically accurate.
- Uses clear and reproducible examples.
- Does not include real proxy credentials.
- Does not include API keys or private information.
- Uses HTTP or SOCKS5 proxy examples where applicable.
